# AI2LEARN

Este repositorio tiene el propósito de crear un LMS pensado desde la IA.

## Flujo de trabajo con IA

idea difusa
    ↓
/wayfinder (si requiere varias sesiones) o  /grill-with-docs (si es algo mucho mas claro)
    ↓
/to-spec
    ↓
/to-tickets
    ↓
/implement × N   ←  cada uno corre /tdd internamente
    ↓
/code-review     ←  antes de cada commit
