Condicionales anidados y casos límite

Más allá del temario estándar. Opcional. Puedes salir en cualquier momento.

¿Cuándo un if dentro de un if se vuelve un problema?

Analiza este fragmento. ¿Cuántos caminos de ejecución posibles hay? ¿Qué pasa si x = 0?

def clasificar(x, y):
    if x > 0:
        if y > 0:
            return "Q1"
        else:
            return "Q2"
    elif x < 0:
        if y > 0:
            return "Q3"
        else:
            return "Q4"
    else:
        return "eje Y"
Reflexiona antes de responder

¿Qué devuelve la función cuando x=0 e y=-5? ¿Y cuántos casos no están cubiertos?

Análisis

Cuando x=0 la función devuelve "eje Y" sin importar el valor de y. Hay 5 caminos de ejecución. El caso x=0, y=0 (origen) queda agrupado con cualquier punto en el eje Y — puede ser una decisión de diseño o un bug silencioso.

La forma de hacer este código más legible sin perder precisión es usando early returns o una tabla de decisión. Esto se llama complejidad ciclomática y es una métrica real de calidad de código.
