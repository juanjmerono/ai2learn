# Agentes

## Agent skills

### Issue tracker

Issues viven como archivos markdown bajo `.scratch/`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Labels por defecto: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `CONTEXT.md` en la raíz + ADRs en `docs/adr/`. Ver `docs/agents/domain.md`.
